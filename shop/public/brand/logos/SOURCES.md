# Логотипы брендов

Файлы с Wikimedia Commons (лицензия у обоих — Public domain, простые текстовые логотипы).
Товарные знаки принадлежат их владельцам; используются для обозначения брендов, которыми торгует магазин.

- chanel.svg — https://commons.wikimedia.org/wiki/File:Chanel_logo.svg
- dior.svg — https://commons.wikimedia.org/wiki/File:Dior_Logo.svg

Чтобы добавить логотип: положите SVG сюда с именем из списка LOGOS в src/components/home-sections.tsx.
Если файла нет, на сайте показывается название бренда.
